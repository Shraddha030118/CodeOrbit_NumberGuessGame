# 🎯 Number Guessing Game

A simple **Number Guessing Game** built using Python. The computer generates a random number, and the player tries to guess it correctly.

## 📌 About the Project

The goal of this project is to create a simple command-line game where the user guesses a randomly generated number.

After each guess, the program provides a hint to help the player:

* 📈 The guessed number is too low
* 📉 The guessed number is too high
* 🎉 The guessed number is correct

## ✨ Features

* Generates a random number
* Takes guesses from the user
* Provides hints after each guess
* Counts the number of attempts
* Displays a success message when the number is guessed correctly
* Simple command-line interface

## 🛠️ Technologies Used

* **Python**
* `random` module
* Command Line Interface (CLI)
